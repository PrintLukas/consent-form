# Vetter Consulting – Einwilligungsformular

Static informational page (Next.js App Router) covering Microsoft Teams
meeting recording/transcription via Happy Scribe: what's processed, why, and
the full Art. 13 DSGVO privacy notice. No personal data is collected and
there's no backend — it's a plain static page.

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploying to Vercel

Push this repo to GitHub and import it at [vercel.com/new](https://vercel.com/new)
(or run `vercel` from this directory) — no configuration needed, the Next.js
app lives at the repo root and has no environment variables to set.
